# PUBPOL 553 — Class 1

A screen-sharing webpage for the first class session, **Four Questions for Better Policy Decisions**.

## Open the class page

https://jwolfers.github.io/pubpol553/class1.html

## Controls

- Left/right arrows or Page Up/Page Down: move between screens
- F: enter full screen
- T: start or pause an activity timer
- Home/End: jump to the first or last screen
