# PUBPOL 553 class pages

Screen-sharing webpages for PUBPOL 553.

## Open the class pages

- [Class 1 — Four Questions for Better Policy Decisions](https://jwolfers.github.io/pubpol553/class1.html)
- [Class 2 — Demand Is a Set of Plans](https://jwolfers.github.io/pubpol553/class2.html)

## Controls

- Left/right arrows or Page Up/Page Down: move between screens
- F: enter full screen
- T: start or pause an activity timer
- Home/End: jump to the first or last screen

On the Class 2 live-demand screen, enter the headcount at each price and choose **Draw curve**. The page checks that quantity does not fall as the price falls before drawing the market demand curve.
